# 社区设施巡检闭环台

社区设施巡检闭环台是一个由 Go 提供的本地浏览器工作台，帮助社区设施巡检员创建巡检计划、按顺序记录现场观测、提交异常复核，并在完成后生成可追溯的巡检报告。数据默认保存在本地 JSON 快照中，适合在单机或内网环境使用。

## 构建

```text
go build ./...
```

## 运行

```text
go run .
```

默认访问地址为 `http://127.0.0.1:8080`。可通过 `INSPECTION_ADDR` 修改监听地址，通过 `INSPECTION_DATA` 修改 JSON 数据文件路径。

## 测试

```text
go test ./...
go run . selfcheck
```

`selfcheck` 会在临时目录中走完创建计划、记录观测、复核异常、关闭计划和读取报告的完整流程，不会改动默认数据文件。

## 工作台能力

- 新建计划时会按规范化后的点位名称和位置检查重复登记，同名设施在不同位置仍可分别加入路线。
- 异常复核队列支持选择同一计划的多条待复核观测，统一填写复核人和意见后批量通过或退回。
- 被退回的异常可在计划关闭前填写整改人和说明后重新提交复核，计划详情与最终报告会保留完整复核历史。
- 进行中或已关闭计划都可复制路线，服务端会为新计划和点位重新生成标识，复制结果从版本 1 的首个点位重新开始。
- 关闭报告会固定保存正常、轻微、较重、严重四档等级统计，以及无需复核、待复核、已通过、已退回四种复核结果统计，并纳入报告校验值。
- 计划台账支持单日期或起止日期、类别、计划状态、异常等级、复核状态与关键词组合筛选，并同步显示当前结果的计划进度和异常汇总；最近观测会显示同一筛选结果的分布统计。
- 计划台账可沿用当前全部筛选条件导出观测明细 CSV，文件包含计划、点位、观测内容和复核信息，便于归档、交接和线下统计。
